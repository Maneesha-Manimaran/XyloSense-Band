How to Test

  1. Open this project using VS Code Live Server.
  2. Open the browser Developer Console (F12).
  3. Make sure the laptop and ESP32 are on the same network.
  4. Open Sensors to see the readings table.
  5. Check Firestore Console to verify saved documents.
